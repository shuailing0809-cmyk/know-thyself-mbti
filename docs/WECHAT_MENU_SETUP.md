# 微信公众号菜单配置说明

## 当前发布方式

个人公众号先采用 H5 链接方式发布：

```text
公众号自定义菜单 → 跳转网页 → H5 测评链接
```

这种方式不需要用户在公众号聊天框内逐轮对话，体验更稳定，也不依赖复杂接口权限。

## 你需要在公众号后台操作

1. 登录 `https://mp.weixin.qq.com`。
2. 进入左侧 `互动管理`。
3. 点击 `自定义菜单`。
4. 点击 `+ 添加菜单`。
5. 菜单名称填写：

```text
开始测评
```

6. 菜单类型选择：

```text
跳转网页
```

7. 网页地址填写部署完成后的 HTTPS 链接：

```text
https://待部署域名/
```

8. 先点击 `预览`，确认手机端可以打开。
9. 确认无误后点击 `保存并发布`。

## 自动回复建议

如果你想设置关键词自动回复，可以在 `互动管理 → 自动回复` 中添加：

关键词：

```text
测评
MBTI
开始
```

回复内容：

```text
欢迎来到 Know-Thyself Journey。

你可以点击这里开始 MBTI 对话式测评：
https://待部署域名/

这不是一个固定标签测试，而是通过 4 个情境问题，帮助你看到自己的自然偏好、外显策略和内在成本。
```

## 注意

- 不要把账号密码发给任何人。
- AppSecret 暂时不需要启用。
- 第一版不需要配置服务器 URL、Token、EncodingAESKey。
- 如果后续要做公众号聊天框内测评，再进入开发配置。
