# 资料问题记录

第二阶段实现中发现以下资料问题，已按“最小修正、不改变测评逻辑”的原则处理。

## 1. TF 追问文本错字

来源文件：

- `04_问题设计原则.md`
- `06_问题库.csv`
- `08_对话流程设计.md`

问题：

- 部分文本出现 `什��`。
- 部分文本将“担心对方不高兴”写成“担心对方高兴”或“不高心”。

处理：

- 运行时显示问题时修复为“什么”和“不高兴”。
- 不改变 TF 维度追问逻辑，仍然用于识别“原则/安排”与“关系/感受”的默认权重。
