# 公众号发布授权与协作边界

## 一、原则

公众号后台控制权保留在账号管理员手里。

我负责：
- 产品代码开发与测试。
- H5 页面发布包。
- 部署配置。
- 菜单、自动回复、隐私说明等配置文案。
- 上线前测试清单。

你负责：
- 登录公众号后台。
- 扫码确认登录。
- 不向任何人发送账号密码、验证码或 AppSecret。
- 在关键发布动作前做最终确认，例如“保存并发布”。

## 二、当前第一版不需要的权限

第一版采用“公众号菜单跳转 H5 页面”的方式，不需要配置：
- 服务器 URL
- Token
- EncodingAESKey
- AppSecret
- 消息回调接口

也不需要把公众号聊天框接成实时 AI 对话。

## 三、你如何授权我继续推进

### 方式 A：你按我给的步骤操作

适合最安全的方式。

流程：
1. 我完成部署，给你一个 HTTPS 测评链接。
2. 我给出公众号菜单配置文字。
3. 你登录公众号后台。
4. 你按步骤配置“开始测评”菜单。
5. 你预览确认。
6. 你点击“保存并发布”。

### 方式 B：你登录后让我远程指导

适合你想让我一步步看着你操作。

流程：
1. 你登录公众号后台并保持页面打开。
2. 你截图或描述当前页面。
3. 我告诉你下一步点哪里、填什么。
4. 到“保存并发布”前，我会停下来让你确认。

## 四、什么时候才需要开发接口授权

只有当我们决定做“用户在公众号聊天框里直接测评”时，才需要进入：

```text
设置与开发 → 开发接口管理 → 基本配置 / 服务器配置
```

到那时才会涉及：
- 服务器 URL
- Token
- 消息验签
- openid 会话状态
- 微信消息回复时限

第一版暂不走这条路，先用 H5 产品验证体验和反馈质量。
