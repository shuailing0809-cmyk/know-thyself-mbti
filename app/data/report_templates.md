# MBTI 输出报告模板

## 报告结构

### H 层：完整报告（高清晰度）

```
你的 MBTI 倾向分析

类型结论：XXXX（XX型）
倾向强度：在大多数场景下较稳定

四维得分：
- EI（能量来源）：X分
- SN（信息偏好）：X分
- TF（决策权重）：X分
- JP（生活节奏）：X分

[类型说明] — 调用 MBTI_KNOWLEDGE.md，适度整合核心特质 + 工作生活表现 + 沟通风格 + 压力反应

[压力表现] — 可根据维度强度决定展开程度

[团队合作] — 同上

相邻类型提示（如果有维度是4或7）：因为你在 X 维度上接近平衡，你可能在 XX 与 YY 之间切换。

*这不是结论，只是倾向。人是复杂的，任何测评都只能提供一个参考方向。*
```

### M 层：简化报告（中等清晰度）

```
你的 MBTI 倾向分析

类型结论（参考方向）：XXXX
说明：你的结果在某些维度上呈现一定倾向，但并非全部维度都足够清晰，以下分析供参考。

四维得分：
- EI（能量来源）：X分  [稳定倾向 / 接近平衡]
- SN（信息偏好）：X分  [稳定倾向 / 接近平衡]
- TF（决策权重）：X分  [稳定倾向 / 接近平衡]
- JP（生活节奏）：X分  [稳定倾向 / 接近平衡]

稳定维度：你的 EI、SN 呈现较为清晰的倾向...
平衡维度：你的 JP 在 5-6 分附近，你在 [维度] 上有一定灵活性，在不同场景下可能会呈现不同的面向。

相邻类型提示：因为 X 维度接近平衡，你可能在 XX 与 YY 之间切换。

类型说明（简要）：XXXX...（简洁整合，2-3段，不展开压力/团队等子项）

你在 [不稳定维度] 上有一定灵活性，在不同情境下可能会呈现不同的面向。建议以探索的心态对待这些描述，而非当作固定答案。

*这不是结论，只是倾向。人是复杂的，任何测评都只能提供一个参考方向。*
```

### L 层：极简报告（低清晰度）

```
当前倾向（参考方向）

基于本次对话，你目前最可能的类型方向是 XXXX，但请注意：你的多个维度处于平衡区间或存在情境依赖，当前的判断参考性有限。

四维得分：
- EI（能量来源）：X分  [不稳定]
- SN（信息偏好）：X分  [不稳定]
- TF（决策权重）：X分  [不稳定]
- JP（生活节奏）：X分  [不稳定]

不稳定维度：你在 EI、SN、JP 上的倾向都接近平衡，信息不足以支撑明确的判断。

相邻类型提示：当前倾向可能为 XXXX 或 YYYY，建议进一步探索后再下定论。

目前阶段，建议把这次测评当作一个思考入口而非结论。你可能在不同场景、不同状态下呈现不同的面向，这本身并不是「矛盾」，而是人性的丰富。

*这不是结论，当前信息不足以支撑确定的类型判断。*
```

## 报告内容说明

### 1. 类型结论（倾向）

- 清晰度高：输出「XXXX（XX型）」
- 中等：输出「XXXX（参考方向）」
- 低：输出「当前倾向（参考方向）」

### 2. 四维得分

- 每个维度的得分（1-10分）
- 标注稳定/平衡/不稳定

### 3. 强弱说明

- 1-3或8-10：「在大多数场景下较稳定」
- 4或7：「但会受场景影响，偶尔呈现另一端」
- 5-6：「在不同情境下可能切换」

### 4. 相邻类型提示

- 找到5-6分的维度
- 生成1-2个相邻类型
- 说明原因

### 5. 类型说明

- 核心特质
- 工作生活表现
- 沟通风格
- 压力下的反应

### 6. 压力表现

- 压力下的典型反应

### 7. 团队合作

- 可能的陷阱
- 正向路径

- MBTI 是理解工具，不是绝对标签

## 语言要求

| 要求 | 说明 |
|------|------|
| 不要太学术 | 不用「构念」「效度」「样本」等词 |
| 不要像测试后台 | 不用「D1≥3」「confidence≥0.65」等内部术语 |
| 不要贴标签 | 不用「你是 XX 型」「确诊 XX」 |
| 第一眼知道重点 | 标题直接给类型结论或参考方向 |
| 结构感和可读性 | 分块清晰，段落简短 |
